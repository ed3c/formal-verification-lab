# C0 P3 execution

The Lab keeps the public source projection and the P3 checker inputs in tracked files. It writes command receipts, backend logs, and ITF traces to the evidence directory supplied at runtime.

Run the pinned checker from the repository root:

```sh
FVL_TOOLCHAIN=/path/to/pinned/toolchain FVL_EVIDENCE_DIR=/path/to/evidence bash scripts/check_models.sh
```

The command typechecks `specs/operation.qnt` and `specs/canary.qnt` without `--main`. It then runs the bounded safety query at 12 steps, the unsafe canary at 2 steps, terminal and reconciliation reachability at 12 steps, and the three TypeOK induction obligations. The bounded and canary queries use the repository specs directly. The reachability and induction harnesses import `specs/operation.qnt`.

The command exits successfully only after `scripts/p3/validate.py` reads the structured Quint results, the Apalache logs, and the ITF traces. A nonzero checker exit is accepted only for the deliberate canary and reachability queries after their actual violation traces match the expected witness. A process error, timeout, missing result, or malformed trace fails validation. If the worker cannot bind a fresh ephemeral local port, the runner writes a capability receipt with `status` `NOT_RUN` and stops the checker-dependent queries. It never falls back to port `8822`.

Each invocation receipt records SHA-256 digests for the model, harness, runner, validator, repository specs, manifest, and pinned toolchain inputs before each process starts. The runner checks the same inputs after each process and rejects changes.

The result remains bounded evidence for the candidate abstract model. It does not establish Quint to Python parity, liveness, Native Soodles conformance, external authorization, or production acceptance.

The original C0 run remains not verified. Its failed receipts and non-delivery history are preserved outside this repository. The C0b worker typechecked both repository specs successfully. The restricted worker could not bind a local port, so checker acceptance remains not run and must be performed by the authorized outer Session.
